# Win95/98 Desktop Experience Plan

## Phase 1: Desktop Shell

- Replace the conventional site chrome with a full-screen desktop surface.
- Add a fixed taskbar with Start button, active application title, clock, and status area.
- Keep the existing page routes, but present them as windows/programs on the desktop.

## Phase 2: Desktop Navigation

- Add desktop icons for Home, About, Services, Contact, My Computer, Network, and Recycle Bin.
- Add a Start menu with primary routes, quick actions, and a shutdown-style footer.
- Keep keyboard and pointer behavior simple: links should remain real route links.

## Phase 3: Visual Treatment

- Strengthen Win95/98 colors, borders, inset/outset controls, wallpaper, icon labels, and selection states.
- Move generic site spacing toward desktop/window spacing.
- Keep text readable with the current safe font stack.

## Phase 4: Window Behavior

- Make routed pages feel more like applications: title bars, status strips, and optional window controls.
- Improve existing draggable windows on the home page so they sit naturally inside the desktop.
- Add small ambient details such as desktop note/status widgets if they do not block content.

## Phase 5: Polish And Verification

- Check desktop and mobile layouts.
- Verify all routes, Start menu links, desktop icons, form fields, and mobile navigation.
- Build before committing or deploying.
